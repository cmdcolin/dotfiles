## Code

- Make code self-explanatory, with minimal or no comments, however heavily the
  surrounding code is commented
- TypeScript: aim for correct types without `any` or typecasts; let return
  types be inferred
- Nest ifs or use ternaries instead of early returns

## Writing

- Use bullet lists, not numbered ones, in markdown and tests

## Git

- I open PRs myself
- Work on a short-lived worktree branch that lands on main as a fast-forward
